# Bounce!

Bounce! is a 2D puzzle game built with Unity and C#. Drag the ball back like a catapult, release it, and plan each bounce to reach the finish line.

## Gameplay

- Aim and launch the ball with a drag-and-release control.
- Use bounces to navigate each level.
- Plan your shots to reach the finish line.

## Play

[Play Bounce! on itch.io](https://althafm.itch.io/bounce).

## Open the project

Clone or download this repository, then add the project folder in Unity Hub. Open it with Unity **6000.3.9f1**, the version recorded in `ProjectSettings/ProjectVersion.txt`.
